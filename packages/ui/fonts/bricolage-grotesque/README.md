# Bricolage Grotesque

Unmodified Latin and Latin Extended WOFF2 subsets, normal weights 700 and 800, from `@fontsource/bricolage-grotesque@5.3.0`:
https://registry.npmjs.org/@fontsource/bricolage-grotesque/-/bricolage-grotesque-5.3.0.tgz

Copyright 2022 The Bricolage Grotesque Project Authors (https://github.com/ateliertriay/bricolage), SIL Open Font License 1.1. The license is `OFL.txt` beside the fonts; each app that serves them also publishes it at `public/licenses/BricolageGrotesque-OFL.txt`. `bricolage-grotesque.css` keeps the upstream Unicode ranges and references only these files. The design system sets headings and amounts in it.
