# Plus Jakarta Sans

Unmodified Latin and Latin Extended WOFF2 subsets, normal weights 400, 600, 700 and 800, from `@fontsource/plus-jakarta-sans@5.3.0`:
https://registry.npmjs.org/@fontsource/plus-jakarta-sans/-/plus-jakarta-sans-5.3.0.tgz

The license is `OFL.txt` beside the fonts; each app that serves them also publishes it at `public/licenses/PlusJakartaSans-OFL.txt`. `plus-jakarta-sans.css` keeps the upstream Unicode ranges and references only these files.
